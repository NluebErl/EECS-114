# EECS-114
Data structures and algorithms implementation.
All data structures and algorithms were written in the C language and compiled using gcc.

Here is the breakdown of what topics each Lab covers:

Lab 2:
Insertion Sort and Merge Sort

Lab 3:
Binary Search and Linear Search

Lab 4:
Brute Force Max Subarray and Divide and Conquer Max Sub Array

Lab 5:
Heap Sort and the Heap data structure

Lab 6:
Quick Sort and Radix Sort

Lab 7:
Linked List and Stack data structures

Lab 8:
Binary Search Trees (BST)

Lab 9:
Depth First Search (DFS)

Lab 10:
Dijkstra's Algorithm

Note: There were many more data structures and algorithms that were learned from this course; these were just the few selected to be part of the lab sessions.
